# tiny-chess

A tiny Python chess engine (under 4 KB) for the [tiny-chess-01](https://make.fun/bounty/tiny-chess-01) bounty.

[![make.fun · tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01?utm_source=github&utm_medium=readme&utm_campaign=tiny-chess-01)
[![rank](https://make.fun/badge/tiny-chess-01/sw897636-web/tiny-chess/rank.svg)](https://make.fun/bounty/tiny-chess-01/leaderboard?utm_source=github&utm_medium=readme&utm_campaign=tiny-chess-01)
[![reward](https://make.fun/badge/tiny-chess-01/sw897636-web/tiny-chess/reward.svg)](https://make.fun/bounty/tiny-chess-01?utm_source=github&utm_medium=readme&utm_campaign=tiny-chess-01)

Alpha-beta search with quiescence, transposition table, killer moves, MVV-LVA ordering, and piece-square tables. Deterministic: fixed node budget per move.
